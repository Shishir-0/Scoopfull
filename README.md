# Scoopfull 🍨

> Artisanal Ice Cream & Gelato Parlour, Franchise Opportunity Portal, and Partner Management Platform.

Scoopfull is a modern web application built with React, TypeScript, and Vite. It serves as the primary digital presence and franchise investor portal for Scoopfull.

## ✨ Features

- **Storefront & Menu Exploration**: Showcase of signature flavours, dietary categories, and parlour locations.
- **Franchise & Partner Programmes**: Detailed models (FOFO / FOCO), unit economics comparison, investment breakdown, and timeline.
- **Interactive Qualification Wizard**: Multi-step partner application and qualification assessment with instant viability feedback.
- **Franchise Partner Portal & CRM Dashboard**: Secure dashboard to review incoming applicant leads, stage management, status updates, and notes.
- **WhatsApp Integration**: Direct click-to-chat messaging for franchise inquiries.
- **Downloadable Prospectus & Guides**: PDF partner guides and investment prospectuses.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Language**: TypeScript
- **Bundler & Dev Server**: Vite
- **Icons**: Lucide React
- **Styling**: Vanilla CSS Design System with custom design tokens

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Shishir-0/Scoopfull.git
   cd Scoopfull
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.

### Production Build

To build the project for production:
```bash
npm run build
```

To preview the built production site locally:
```bash
npm run preview
```
